## 📖 О проекте

Новые горизонты — это интерактивная визуальная новелла, где ваши выборы определяют развитие истории и отношений с персонажами.

### Особенности
- 🎭 4 уникальных персонажа — каждый со своей историей и характером
- 💕 Романтические линии — развивайте отношения с понравившимся персонажем
- 🔀 Разветвлённый сюжет — ваши решения влияют на историю
- 🏆 Система достижений — открывайте секреты
- 💾 Автосохранение — прогресс сохраняется автоматически
- 🎨 Атмосферный текст — погрузитесь в историю
